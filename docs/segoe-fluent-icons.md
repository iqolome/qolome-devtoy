# Segoe Fluent Icons 离线参阅

> 整理自 Microsoft Learn《Segoe Fluent 图标字体》（约字体版本 1.56），供本仓库离线查阅。
>
> 在线原文：[Segoe Fluent Icons](https://learn.microsoft.com/zh-cn/windows/apps/design/style/segoe-fluent-icons-font)
>
> 本机字体：`%WINDIR%\Fonts\SegoeIcons.ttf`（字体族名 `Segoe Fluent Icons`）

## 在本项目中的用法

- **Symbol 枚举内已有**：`SymbolIcon` / `DevtoyButtons.BuildContent(label, Symbol.Xxx)`
- **枚举外字形**：`FontIcon` + Unicode，或 `DevtoyButtons.BuildContentWithGlyph(label, "\uXXXX")`
- 推荐字号：16 / 20 / 24 / 32 / 40 / 48 / 64

```csharp
// Symbol
DevtoyButtons.BuildContent("查询", Symbol.Find);

// FontIcon 字形（示例：ChevronDown）
DevtoyButtons.BuildContentWithGlyph("编码", "\uE70D");
```

```xaml
<FontIcon FontFamily="Segoe Fluent Icons" Glyph="&#xE70D;" />
```
